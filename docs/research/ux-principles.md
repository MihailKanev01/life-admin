# UX Principles

## 1. Attention first

Home is not a statistics dashboard. Its job is to answer "What needs my attention?"

## 2. Summary first, detail second

Use progressive disclosure. Start with the smallest useful summary and reveal details only when the user asks for them.

## 3. Lists for repeated items, cards for mixed information

Lists are easier to scan when items are homogeneous. Cards should be reserved for different content types or important groupings.

## 4. Top-level navigation stays small

Web desktop can use a compact sidebar. Mobile should use a small visible tab bar and a prominent Quick Add action.

## 5. Keep actions close to the information they change

For example, a reminder should have a clear Done and Snooze/Reschedule path without opening another settings screen.

## 6. Empty states are product UX

When nothing needs attention, show a calm state rather than an empty database feeling.

## 7. Avoid notification overload

The system should prefer one useful summary over many low-value notifications.

## 8. Accessibility and responsive behavior are requirements

Keyboard navigation, semantic HTML, focus states, readable contrast, sensible spacing and mobile touch targets must be considered from the start.
