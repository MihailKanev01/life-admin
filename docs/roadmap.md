# Product Roadmap

## Phase 0 — Product Discovery
**Goal:** decide what is worth building.

Deliverables:
- research synthesis
- competitor matrix
- target-user hypothesis
- top jobs/tasks
- MVP candidates
- UX principles
- visual direction
- validation plan

Status: in progress

## Phase 1 — User Validation

- recruit interview participants
- run 10–15 interviews
- synthesize recurring problems
- update persona/JTBD
- lock core user flows

Gate: repeated pain and clear top tasks.

## Phase 2 — Information Architecture + Wireframes

- onboarding
- Home
- Things
- Thing detail
- Payments
- Search
- Quick Add
- Reminder flow
- Document flow

Gate: users can complete core flows without explanation.

## Phase 3 — Prototype + Usability Testing

- build clickable prototype
- test with ~5 users from the initial target group
- record friction
- revise

Gate: critical flows are understandable and efficient.

## Phase 4 — Visual Design

- design system
- typography
- spacing
- color semantics
- responsive states
- accessibility states

## Phase 5 — Technical Architecture

- repository structure
- frontend/backend split
- database ERD
- API contract
- auth
- file storage
- notifications
- permissions
- security/GDPR baseline

## Phase 6 — Web MVP

Build only validated must-haves.

## Phase 7 — Beta

Measure activation, retention, reminder quality, search success and user feedback.

## Phase 8 — Mobile

Build mobile clients against the existing API after the web product proves demand.
