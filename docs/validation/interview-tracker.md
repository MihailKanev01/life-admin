## Per-session evidence

For each participant, record:
- current workaround in their own terms;
- one recent real admin example;
- what they had to remember manually;
- what they had to search for or reconstruct;
- observed task behavior;
- exact quotes, clearly marked as quotes;
- strongest positive signal;
- strongest negative signal;
- product implication.

## Core task scoring

Use the 0 / 1 / 2 scale from `docs/validation/phase1-field-kit.md`:

- Quick Add
- Context review
- Thing retrieval
- Generic vs Life Admin comparison

Also record:
- time to first useful action;
- wrong turns;
- help requests;
- confidence (1–5);
- preference;
- perceived maintenance burden.

## Interview quality checklist

For every interview:
- [ ] Asked for recent real examples
- [ ] Mapped current workflow before showing Life Admin
- [ ] Identified tools used today
- [ ] Identified workaround
- [ ] Identified frequency and consequence
- [ ] Recorded exact user language
- [ ] Observed behavior instead of relying only on opinions
- [ ] Tested generic baseline
- [ ] Tested Life Admin
- [ ] Asked what would make them return to current workflow
- [ ] Avoided pitching or defending the product
- [ ] Used demo data only
- [ ] No sensitive credentials/documents collected
