## Interview quality checklist

For every interview:
- [ ] Asked for recent real examples
- [ ] Mapped current workflow
- [ ] Identified tools used today
- [ ] Identified workaround
- [ ] Recorded frequency
- [ ] Recorded consequence of failure
- [ ] Recorded exact user language
- [ ] Avoided pitching before behavior questions
- [ ] Captured what they would stop doing if our product existed
